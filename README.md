# Alix & Buck - V3

Aventure pour Alix : cinq étapes, jauge de confiance, 20 questions, indices, soins, vol avec deux poses de Buck, trois types d'obstacles et pause.
Quiz libre : 82 cartes, niveaux de difficulté, solo ou Alix contre Nicolas sur le même écran.
Certificat PDF téléchargeable avec portrait et message personnalisé.
Sauvegarde de progression et certificat dans le navigateur utilisé (pas de synchronisation entre appareils).

## Jouer
Ouvrir index.html ou déposer tout le contenu dans le dépôt GitHub Pages, en conservant le sous-dossier vendor et toutes les images. Aucun réglage Firebase nécessaire.

## Commandes du vol
Flèches haut et bas, espace pour pause. Sur téléphone : glisser le doigt dans le ciel ou utiliser les boutons. Attraper dix étoiles. Les collisions retirent une étoile.

PDF généré localement avec pdf-lib, sans dépendance réseau. Illustrations générées pour ce jeu de fan non officiel.
